# FrilAdd v0.2.0 (release candidate; unpublished)

This document prepares the v0.2.0 release. The version is not published. Release remains blocked on the FrilAssets reviewed asset and FrilRemotion published composition requirements listed in [the qualification report](../distribution-roadmap.md).

## Highlights

- Managed, idempotent installation with ownership lock, status, safe update/remove/restore, and recoverable project transactions.
- Registry v2 metadata, portable target mapping, explicit cross-registry dependency resolution, and advisory package requirement reporting.
- Bounded large-file streaming and SHA-256 verification before transaction commit.
- Deterministic list/search/info output, versioned JSON, offline doctor diagnostics, and registry verification.
- Provider-independent CLI with Registry v1 compatibility and platform-specific npm binaries.

## Install and upgrade

After release authorization and publication, install with:

```sh
npm install --global friladd@0.2.0
# or run without a global install:
npx --yes friladd@0.2.0 --help
```

Upgrade an existing global install with:

```sh
npm install --global friladd@0.2.0
friladd --version
```

The project configuration (`.friladd.json`), lockfile (`friladd.lock.json`), Registry v1 manifests, and existing command forms remain separately versioned and compatible. Before lifecycle operations on projects installed by earlier FrilAdd versions, inspect state with `friladd installed` and `friladd status`; v0.2.0 will not silently claim pre-existing unmanaged files.

Use `friladd --help` for the command list. See [README](../../README.md), [CLI contract](../cli-contract.md), [security model](../security-model.md), [Registry v2 contract](../registry-v2.md), and [lock/recovery contract](../lock-and-recovery.md).

## Supported packaged targets

The release workflow builds and smoke-tests npm packages containing native binaries for Linux x64 (GNU), macOS ARM64, macOS x64, and Windows x64 (MSVC). Linux ARM64 is not currently a supported packaged target.
