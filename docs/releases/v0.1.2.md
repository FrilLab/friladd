# FrilAdd v0.1.2

FrilAdd v0.1.2 is a **maintenance release** that removes repository-only Registry fixtures from the published npm package. The Rust CLI and Registry workflow remain unchanged.

## Changes

- **Lean, provider-independent npm package:** no example Registry, example components, or development fixtures are bundled in `friladd`. The package contains the Node executable wrapper, supported platform-specific Rust binaries, and package metadata, README, and license.
- **Build pipeline cleanup:** native artifact staging and local npm package checks no longer copy the repository's `registry/` fixture directory into the npm package.
- **Real consumer testing without bundled fixtures:** packed npm smoke tests load fixture manifests and source files from the source checkout and explicitly verify that the installed npm package does not contain `registry/`.
- **Reproducible fixture hashes:** Git checkout rules preserve exact fixture bytes on Windows, macOS, and Linux, avoiding line-ending changes that would invalidate SHA-256 checks.

## Usage

Register a compatible third-party Registry once:

```bash
npx --yes friladd@0.1.2 registry add my-ui https://example.com/registry.json --global --default
```

Then list or install items from that Registry:

```bash
npx --yes friladd@0.1.2 list
npx --yes friladd@0.1.2 add my-component --dry-run
npx --yes friladd@0.1.2 add my-component
npx --yes friladd@0.1.2 add my-ui/my-component
```

Replace the example URL and item name with an actual Registry provider and its component identifier. You can still use a local manifest or HTTPS URL directly with `--registry`; no registration is required for an explicit URL.

## Compatibility

- No breaking CLI changes or changes to Registry Manifest v1.
- Project and global Registry registration, aliases, configured defaults, and explicit `--registry` remain supported.
- Existing SHA-256 verification, safe path validation, `--dry-run`, and refusal to overwrite installed files remain unchanged.
- Development fixtures remain available in the [FrilAdd source repository](https://github.com/FrilLab/friladd/tree/main/registry), but are not part of the npm distribution.
- Supported native platforms remain macOS ARM64/x64, Linux x64, and Windows x64.

See the [README](https://github.com/FrilLab/friladd#readme) for the complete CLI and security model.
